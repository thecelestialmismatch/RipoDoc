Moving from transparency to execution, seven distinct decision domains block our contractual launch. We have published status transparency rather than inventing legal commitments prematurely. # 8 - Healthcare Mode B is a guardrail, not a compliance claim

When it comes to healthcare, we draw a hard line. Healthcare Mode B is a strict technical guardrail, not a compliance claim or a shortcut to HIPAA certification. Public hosted planes block all regulated data outright. Private self-hosted paths require an explicit, deliberate operator-controlled decision. Nothing opens automatically without full legal and security review.

# 9 - Webhook controls start disabled and precise

Building on that boundary context, let's look at how we handle integrations. Webhooks start strictly disabled and precise. We don't expose arbitrary callbacks. Every integration requires an explicit enablement variable, a non-empty allowlist, and exact HTTPS matching. We reject unsafe URLs, private networks, and local ports entirely. When payloads emit, they stay safe. We only send ID, type, timestamp, and optional correlation ID—never report or recipient data. And if Healthcare Mode B is enabled, webhook delivery still remains shut off. No healthcare provider webhook is enabled here. We verified our exact-host policy and event schema, but we are not claiming active provider integration. Now let's map how we turn this code into actual evidence.

Success means repeated paid cycles, not premature claims.
