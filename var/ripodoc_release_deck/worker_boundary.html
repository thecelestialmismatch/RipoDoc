The Private Worker Boundary

The PDF authoring worker is now unreachable from the browser. All authoring operations are gated by a trusted server-side capability issuer.

  • Capability-Based Auth
    Server-issued, single-use, 90-second HMAC tokens.
  • Tenant Isolation
    Worker enforces tenant ID and draft ID matching.
  • Approval Integrity
    Publication rechecks source PDF and manifest digests.
