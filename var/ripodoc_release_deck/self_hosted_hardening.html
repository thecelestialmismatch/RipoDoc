Self-Hosted Hardening

Non-Root Runtime

Web and worker services run as a dedicated unprivileged ripodoc user (UID 10001).

USER ripodoc

Read-Only Filesystem

Root filesystems are mounted read-only. Writable state is restricted to bounded tmpfs and named volumes.

read_only: true

Dropped Capabilities

All Linux capabilities are dropped by default. No-new-privileges is enforced to prevent escalation.

cap_drop: [ALL]

Resource Constraints

Strict CPU and memory limits prevent denial-of-service via resource exhaustion.

memory: 768M
