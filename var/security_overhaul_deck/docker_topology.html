05 / Self-hosted topology
docker-compose.selfhost.yml

Self-hosted by design,
not as an afterthought.

Three services create a controlled operating boundary: durable identity, a protected web surface, and a local-only PDF authoring worker.

01 / WEB

Next.js
workspace

Published on port 3000. Receives only HTTPS traffic from the MSP reverse proxy.

→
02 / POSTGRES

Durable
system of record

Internal compose network only. Users, sessions, one-time codes, rate limits, and tenant reports.

→
03 / WORKER

Reviewed PDF
authoring

Host mapping: 127.0.0.1:4000. Never public by default.

HOST-LEVEL GUARANTEES

Web waits for PostgreSQL health.
Required auth, email, Turnstile, and evidence secrets prevent unsafe startup.

Worker allows one exact browser origin.

Persistent volumes: ripodoc-postgres and ripodoc-worker

NETWORK

PostgreSQL has no host port. The worker remains loopback-only on the deployment host.

SECRETS

Compose requires long database, auth, and evidence secrets plus verified email and anti-bot settings.

TLS

An MSP-operated HTTPS reverse proxy protects the public web service; Docker Compose does not terminate TLS.
