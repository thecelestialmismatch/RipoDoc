04 / Evidence boundary
RECIPIENT-SCOPED DELIVERY

A PDF can travel.
Its evidence does not.

RipoDoc releases one approved evidence view only after claim validation and intended-recipient mailbox proof.

01

Signed evidence claim

Report, version, recipient hash, expiry, and revocation ID are bound into the claim.

02

Mailbox proof

A one-time code confirms access with the address bound to the signed evidence claim.

03

Scoped release

Only the selected approved figure and its source rows are rendered for the recipient.

04

Access recorded

RipoDoc records the access outcome before evidence rows render in the client view.

Recipient view: evidence is not embedded in the PDF and forwarding the document is not a second authorization.

Workspace view: report manifest downloads require a verified session and matching tenant ownership.

SOURCE: evidence token, recipient-proof, audit, and tenant report authorization implementation
