02 / Identity architecture
DURABLE AUTHORITY, NOT BROWSER STATE

Identity is durable
and fails closed.

Sensitive authentication work runs on the server. PostgreSQL holds authority; email and anti-automation providers are verified before account actions advance.

01

Browser request

Form CSRF value and Turnstile response arrive at a same-origin server endpoint.

02

Next.js boundary

Server routes enforce origin + CSRF checks, generic responses, and safe cookie policy.

03

PostgreSQL authority

Users, tenant ownership, opaque sessions, codes, audit events, and rate limits persist here.

04

Code delivery

Resend receives the raw verification or recovery code; storage retains only its HMAC.

05

Automation gate

Cloudflare Turnstile is verified server-side for production account actions.

FAIL-CLOSED RULE

No durable dependencies,
no account action.

If the database, 32+ character authentication secret, canonical app origin, Resend configuration, sender identity, or production Turnstile settings are missing, the hosted account flow returns unavailable rather than creating ephemeral state or simulating delivery.

authConfigured() → false
account action → blocked
secret exposure → none
